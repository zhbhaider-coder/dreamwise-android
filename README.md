# DreamWise — Dream Journal & Symbol Dictionary (Android)

Free Android dream journal app. Log dreams in seconds, explore 500+ dream symbols, see your zodiac dream profile, and track patterns over time. Private by design — everything stays on your device.

## Download

- **APK (v1.0.2, latest):** https://shadowcodedpsychology.pages.dev/dreamwise
- **Amazon Appstore:** https://www.amazon.com/gp/mas/dl/android?p=com.zohaib.dreamwisecompanion

## Features

- 📓 Dream journal — fast entry, dates, moods, tags (sqflite, on-device)
- 📖 Symbol dictionary — 500+ dream symbols with plain-language meanings
- ✨ Zodiac dream profile
- 📊 Stats — frequency, themes, mood trends
- ⏰ Dream reminders (inexact scheduling, no exact-alarm permission needed)
- 🔒 Private — no account, no cloud, your journal never leaves your phone

## Tech

Built with Flutter. Free with AdMob ads.
